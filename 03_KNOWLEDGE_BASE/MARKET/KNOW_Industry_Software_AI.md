# KNOW: Industry Intelligence — Software, Cloud & AI

## Purpose
Taxonomy, hiring standards, key metrics, and resume evaluation standards for Software Engineering, Cloud Architecture, Data, and AI/ML roles.

---

## Core Domain Taxonomy & Focus Areas

- **Software Engineering**: Microservices, Distributed Systems, API Architecture, CI/CD, Testing (Jest, PyTest), Latency Optimization.
- **AI / ML Engineering**: LLM Fine-Tuning, RAG Architecture, PyTorch, TensorFlow, Vector Databases (Pinecone, Qdrant), GPU Optimization.
- **Data Engineering**: Data Pipelines, Snowflake, Databricks, Apache Spark, dbt, ETL/ELT, Data Modeling.
- **Cloud & DevOps**: Kubernetes, Docker, AWS, GCP, Terraform, Infrastructure as Code (IaC), Observability (Datadog).

---

## High-Impact Target Metrics
- System Uptime / Reliability (`99.99%`).
- Latency Reduction (`ms`).
- Throughput / API Calls (`req/sec`).
- Infrastructure Cost Savings (`$`).
- Deployment Frequency (`deployments/day`).
