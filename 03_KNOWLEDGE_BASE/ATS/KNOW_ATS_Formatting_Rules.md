# KNOW: ATS Formatting Rules & Compatibility Checklist

## Purpose
Defines formatting constraints required to guarantee zero text parsing errors across all major ATS vendors.

---

## The 10 ATS Formatting Rules

1. **Single-Column Architecture**: Avoid sidebars, split columns, or non-linear page regions.
2. **Standard Bullet Points**: Use basic solid round bullets (`•`). Avoid custom icons, arrows, or wingdings.
3. **No Embedded Graphics or Logos**: Images, charts, graphs, and company logos are ignored and corrupt adjacent text line counts.
4. **No Page Headers/Footers**: Keep contact information strictly within the main document body top area.
5. **Clear Section Headings**: Use standard titles: `Professional Summary`, `Work Experience`, `Education`, `Technical Skills`, `Certifications`.
6. **Standard Chronological Order**: List experience in reverse chronological order with clear start and end dates (e.g., `Jan 2021 – Present`).
7. **Clean Date Formatting**: Use standard date formats (`MM/YYYY` or `Month YYYY`).
8. **Consistent Typography**: Use web-safe fonts: Arial, Calibri, Helvetica, Georgia, Times New Roman (font size 10–12pt body, 14–16pt headers).
9. **No Text Boxes or Tables**: Never use Word text boxes or complex nested table containers.
10. **File Naming Convention**: Save files using `FirstName_LastName_Resume.pdf` or `FirstName_LastName_Resume.docx`.
