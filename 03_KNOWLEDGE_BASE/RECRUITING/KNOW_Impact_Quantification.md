# KNOW: Impact Quantification & Metric Modeling

## Purpose
Provides mathematical formulas, metric taxonomies, and estimation methodologies for converting passive job duties into high-impact, quantified bullets.

---

## The 5 Core Business Metric Categories

Every strong resume bullet point ties execution back to one of five core business vectors:

1. **Revenue Growth (`$`, `%`)**: Sales, expansion ARR, upselling, conversion improvements.
2. **Cost Reduction (`$`, `%`)**: Infrastructure savings, vendor negotiations, budget optimization.
3. **Time Efficiency / Speed (`Hours`, `%`, `Velocity`)**: Process automation, build time reduction, workflow streamlining.
4. **Scale & Volume (`Users`, `Requests`, `Volume`)**: Traffic handled, data size processed, team/org size managed.
5. **Quality & Accuracy (`CSAT`, `Uptime`, `Error Rate`)**: Defect reduction, SLA compliance, reliability improvements.

---

## Impact Formula Blueprint (Google XYZ Formula)

$$\text{Accomplished [X]} \text{ as measured by [Y]} \text{ by doing [Z]}$$

- **Weak Bullet**: *"Worked on the search engine and made it faster."*
- **Quantified XYZ Bullet**: *"Reduced search query latency by 45% (from 800ms to 440ms) by re-architecting Elasticsearch indexing pipelines."*

---

## Metric Estimation Framework (For Missing Data)
When candidates claim they *"don't have exact metrics"*, guide them using conservative estimation models:
- *Scale*: How many users, clients, or team members were affected?
- *Frequency*: How often was this task executed (daily, weekly, monthly)?
- *Time Saved*: How many hours per week did the new process save the team?
