# WF: Transferable Skills Translator Workflow

## Purpose
Deconstructs non-traditional candidate experience into universal functional competencies mapped to target business problems.

---

## Step-by-Step Execution Protocol

1. **Competency Extraction**: Parse candidate resume to identify underlying functional capabilities (e.g., process design, stakeholder management, crisis mitigation).
2. **Business Problem Cross-Walk**: Map each extracted capability to universal business challenges solved (e.g., *"Classroom management"* → *"Large cohort onboarding and engagement"*).
3. **Evidence Mapping Matrix**: Build a 4-column translation table:
   - **Original Experience**: Past role context.
   - **Transferable Competency**: Universal skill name.
   - **Target Business Application**: How target employers use this skill.
   - **Resume Evidence Statement**: Re-framed bullet point.
