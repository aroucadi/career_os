# WF: LinkedIn Profile Optimizer Workflow

## Purpose
System for transforming candidate LinkedIn profiles to maximize recruiter searchability, Social Selling Index (SSI), and inbound connection rates.

---

## Step-by-Step Execution Protocol

1. **Profile Audit**: Evaluate current profile against `04_RUBRICS/RUBRIC_LinkedIn_Scorecard.md`.
2. **Headline Optimization**: Generate 3 high-converting headline variations combining: `Target Role Title` + `Core Technical Stack` + `Key Value/Metric Hook`.
3. **About Section Narrative**: Draft a 4-paragraph story-driven About section:
   - *Hook*: Core professional passion and domain focus.
   - *Career Arc*: Key achievements and progression.
   - *Specializations*: Bulleted list of top technical hard skills.
   - *Call to Action*: Openness to networking / recruiter outreach.
4. **Featured & Visuals Brief**: Outline recommended portfolio items, banner concepts, and featured post topics.
