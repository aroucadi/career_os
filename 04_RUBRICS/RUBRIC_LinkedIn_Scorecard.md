# RUBRIC: LinkedIn Profile Optimization Scorecard

## Purpose
100-point audit scorecard for LinkedIn profile completeness, search ranking potential, and recruiter conversion rate.

---

## 100-Point Scoring Breakdown

| Profile Section | Max Points | Evaluation Parameter |
| :--- | :---: | :--- |
| **Headline Impact** | 25 | Value-focused headline with target role keywords and key metric hook. |
| **About Section Narrative** | 25 | Compelling career narrative, top technical skills list, call to action. |
| **Experience Descriptions** | 25 | Quantified bullet points with keyword density matching target roles. |
| **Featured & Visuals** | 15 | Media links, portfolio attachments, professional banner/photo hygiene. |
| **Skills & Endorsements** | 10 | 30+ tagged skills with top 3 pinned to core competency. |
