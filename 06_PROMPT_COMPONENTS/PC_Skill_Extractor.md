# PC: Skill & Entity Extractor Subroutine

## Purpose
Text parsing subroutine that extracts hard technical skills, soft competencies, certifications, and industry tools from unstructured text.

---

## Entity Extraction Taxonomy

- **Programming Languages**: Python, Java, C++, TypeScript, Go, Rust, SQL.
- **Frameworks & Libraries**: React, Next.js, Node.js, PyTorch, TensorFlow, Spring Boot.
- **Cloud & Infrastructure**: AWS, GCP, Azure, Docker, Kubernetes, Terraform, Datadog.
- **Methodologies**: Agile, Scrum, Kanban, CI/CD, TDD, OKRs, RICE Prioritization.
- **Business Tools**: Salesforce, Hubspot, Snowflake, Databricks, Jira, Figma, Tableau.

---

## Standardization Rules
- Standardize non-standard acronyms (e.g., *"JS"* → *"JavaScript"*, *"K8s"* → *"Kubernetes"*, *"ML"* → *"Machine Learning"*).
